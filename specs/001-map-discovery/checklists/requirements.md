- [x] 원본 확정·제안·미정 상태를 구분했다.

## 남은 사항

- 첫 구현의 M-01~05·MC-01~05는 사용자의 설계 진행 지시로 승인됐다.
  이번 구현은 이 범위와 FR-001·FR-006~009로 한정한다.
  전체 제품의 위치 생성·승인자 권한 정책은 후속 작업으로 유지한다.
- 사용자가 네이버 Maps 애플리케이션·Client ID 준비 완료를 알렸다.
  localhost에서 실제 지도 로딩과 인증을 확인했다. 127.0.0.1에서는 인증 실패를 확인했다.

- 지도 공급자는 2026-10-08 사용자 결정으로 네이버 지도를 사용한다.

- 2026-10-08 지도 상태 갱신에 SSE를 사용하기로 결정했다. 정상 연결에서 마감 확정 후 2초 이내 일반 마커 제거 또는 열린 모달의 마감 표시 전환으로 합의했다. 모달은 안내·비활성 참여 버튼과 함께 유지하고 닫을 때 마감 마커도 제거한다. 첫 구현의 이벤트·복구·재조회 설계와 시험 환경은 승인됐으며 제거 애니메이션은 이번 범위에서 제외했다. SSE 구현·검증은 아직 진행하지 않았다.
- 3개 결정 묶음이 남아 있다. 명세의 Q 항목과 연결된 OPEN 항목을 검토한다.
- 전체 제품 관련 미완료 체크는 유지한다. 첫 구현의 설계 문서는 작성했으며,
  사용자 설계 승인 후 지도 표시 Green까지 진행했다. 화면 코드의 사용자 리뷰와 전체 기능 검증은 남아 있다.
- 기능 검증은 관련 SC·AC, 전체 검증은 AC-17·AC-18과 함께 수행한다.
